안녕하세요, 차량운행일지 운영자입니다.

따뜻한 말씀 감사합니다. 문의 주신 덕분에 다른 기관에도 도움이 될 기능을 만들게 되었습니다. 말씀하신 대로 차량별 누적 주행거리와 하이패스 잔액을 읽기 전용으로 조회하는 API를 오늘 열었습니다. 이용료는 없습니다.


■ 사용 준비 (기관 관리자 계정으로)

1. 앱 [설정] → [기능 사용 설정] 맨 아래의 [외부 연동(API)]을 켜 주세요. 처음에는 꺼져 있습니다.
2. 토글 바로 아래에 생기는 '외부 연동(API)' 카드에서 [API 키 발급]을 누르세요.
3. 발급된 키는 그 자리에서 한 번만 보입니다. 바로 복사해 두세요. 잃어버리면 새로 발급하면 됩니다.


■ 접속 방법

- 요청 주소: 카드에 적힌 주소를 복사해 쓰시면 됩니다.
  (예: https://drivelog.socialprism.co.kr/api/v1/vehicles)
- 방식: GET
- 인증: 요청 헤더에 Authorization: Bearer (발급받은 API 키)
- 사용설명서: 카드의 [사용 방법 · 응답 예시 · 구글 앱스 스크립트 예제]를 펼치면 바로 붙여 쓸 수 있는 앱스 스크립트 예제가 있습니다. 앱 [설정]의 '자주 하는 질문'에도 같은 안내를 올려 두었습니다.


■ 받으시는 값

차량마다 이름, 번호판, 누적 주행거리(km), 하이패스 잔액(원), 하이패스 카드 끝 4자리가 옵니다.

- 퇴역 처리한 차량은 빠지고, 운행 중인 차량만 나옵니다.
- 하이패스 카드가 연결되지 않은 차량은 잔액이 비어(null) 있습니다.
- 두 값은 앱에 입력된 기록을 기준으로 계산한 값입니다. 하이패스 잔액은 앱에 기록한 충전·사용 내역으로 계산되므로, 카드사의 실제 잔액과 다를 수 있습니다. 차이가 나면 앱 [하이패스 관리]에서 실제 잔액으로 맞춰 주세요.
- 운행 기록이나 직원 정보처럼 개인정보가 담긴 내용은 내보내지 않습니다.


■ 이용 시 참고

- 기관당 시간당 60회까지 조회할 수 있습니다. 값은 운행일지나 하이패스 기록이 저장될 때만 바뀌므로, 앱스 스크립트 시간 트리거는 1시간에 한 번 정도면 충분합니다.
- 키는 코드에 직접 적지 마시고 앱스 스크립트의 [프로젝트 설정 → 스크립트 속성]에 넣어 두시길 권합니다. 공유 문서나 웹 페이지에도 적지 마세요.
- 키가 새어 나갔다고 생각되면 [새 키로 교체]를 누르세요. 이전 키는 즉시 막힙니다. [외부 연동(API)]을 끄면 키가 있어도 조회가 멈춥니다.
- 앱 로그인 아이디와 비밀번호를 스크립트에 넣어 직접 접속하는 방식은 쓰지 말아 주세요. 계정 전체가 노출될 수 있어서 이 API 키를 따로 마련했습니다.


연동하시다가 막히는 부분이 있으면 앱의 [건의하기]나 이 메일로 편하게 알려 주세요. 앱 만드시는 일 응원하겠습니다. 감사합니다.
